# Operation-Management-Faia-Rent-a-car

This repository serves as a portfolio for an interactive visualization dashboard developed in Data Studio. The project focuses on monitoring and managing operations for a vehicle rental company, utilizing a dummy Excel database to demonstrate functionality and business logic without exposing real operational data.

## 🎯 Project Objective
The main objective of this dashboard is to provide a centralized view of the fleet's status. Key implemented features include:
*   **Dynamic filtering:** Implementation of date filters configured to display the current month's performance and operations by default.
*   **Relational modeling:** Use of data joins to cross-reference operational databases, allowing the direct visualization of vehicle models.

## 🎨 Design and Visual Identity
The dashboard interface was designed with a premium "Dark Mode" aesthetic, ensuring optimal contrast and comfortable reading of metrics. The color palette focuses on:
*   **Accent Color:** Faia Orange (`#FF5000`) to highlight KPIs and interactive elements.
*   **Surfaces:** Charcoal (`#1E242B`) for backgrounds and chart containers.

## 🛠️ Tech Stack
*   **Looker Studio:** Data visualization, UI/UX design, and metrics configuration.
*   **Microsoft Excel:** Structured data source (relational dummy database).
